# Galia — español vivo

User authorized option 1, creative discretion, implementation, GitHub Pages publication, scroll animation and a real leads admin. No further design questions requested.

Job: help a Russian-speaking prospective Spanish learner understand Galia's approach and request a lesson. Static portable HTML/CSS/JS on GitHub Pages; separate Sites Worker and D1 for durable leads. Owner-only admin uses platform sign-in; no password in public code, no browser-local fake CRM.

Direction: Mediterranean editorial language notebook. Warm ivory 70%, terracotta 20%, olive/ink 10%. Manrope for readable Russian, Cormorant Garamond italic for expressive Spanish. Large left-aligned Russian headline, oversized Spanish background, real Galia portrait on a terracotta paper stage. Repeated motif is a handwritten underline/Spanish phrase. No glass, default dashboard tiles, fake testimonials, fabricated numbers or rates.

Sequence: hero → learning goals → interactive phrase notebook (choose situation, show translation, optional system speech) → real introduction and links to source reviews → lesson process → FAQ → two-step request form → footer. Form asks goal/level then name/contact/consent. Submission means request, not confirmed reservation; price/time agreed personally. Failed requests keep values and permit retry. UTM source saved with the request. Success returns opaque reference only. Admin lists, searches, filters, changes status, adds notes, exports CSV; private records never appear on GitHub.

Motion: first-frame content visible; scroll reveals, background phrase translates slowly, notebook changes on interaction. CSS/IntersectionObserver/requestAnimationFrame only. No scroll hijack. Reduced motion disables transforms; mobile stacks content and preserves a visible action. Load/ready/busy/error/empty handled explicitly.

Evidence: Node behavior/security tests, actual deployed write/read/status path, anonymous admin denial, desktop/mobile screenshots, keyboard/form error/recovery, reduced-motion and horizontal overflow checks.
