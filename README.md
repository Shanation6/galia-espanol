# Galia · Español vivo

Индивидуальный сайт преподавателя испанского Гали Романовой.

- Сайт: https://shanation6.github.io/galia-espanol/
- Кабинет: https://galia-espanol-studio.micsonwilktaywilsamu.chatgpt.site/admin/
- Сервер: Sites Worker, база Cloudflare D1. Форма сохраняет настоящие заявки; публичный репозиторий не содержит данных учеников.

## Разработка

Node.js 24+ (для тестов используется встроенный SQLite).

```sh
npm test
npm run preview
npm run build
```

`public/` — исходники сайта; сборка копирует их в `docs/` для GitHub Pages и в `dist/` для локального артефакта. Pages использует ветку `main`, каталог `/docs`.

Серверные исходники находятся в `service/`. Его собственный исходный репозиторий управляется Sites; локальная вложенная Git-метаинформация не публикуется в GitHub. `service/build.mjs` собирает Worker и защищённую HTML-страницу кабинета. Миграции находятся в `service/drizzle/`.

## Заявки и доступ

Для заявки обязательны цель, уровень, имя, корректный контакт и согласие. Время, цена и условия подтверждаются лично; сайт не принимает оплату и не обещает наличие мест.

Кабинет требует входа через ChatGPT и совпадения аккаунта с серверной настройкой `ADMIN_EMAIL`. Сейчас доступ настроен на владельца текущего проекта. Для передачи Гале нужно заменить `ADMIN_EMAIL` на её аккаунт через настройки окружения Sites и опубликовать новую версию. Уроки/форматы и условия стоит подтвердить с Галей до начала привлечения трафика.

В кабинете: поиск, фильтр, статусы, заметки, CSV, окончательное удаление записи. Лист показывает последние 1000 заявок. Есть лимит публичных отправок, защита от случайного дублирования, проверка согласия и ограничение источников запросов. UTM-метки сохраняются в заявке. Счётчик «Записались» отражает установленный администратором статус, а не автоматическую оплату.

Данные не сохраняются в браузерной базе. Только предпочтение анимации хранится локально, и запрет localStorage не мешает записи. Системная озвучка — дополнительная функция, доступная при наличии испанского голоса на устройстве.

## Проверки

`npm test` — валидация, права, CORS, полный SQLite цикл заявки, повторная отправка, изменение и удаление.

`scripts/browser-qa.mjs` — Playwright-проверка формы, сетевой ошибки и повторной отправки с исправленным контактом, запрещённого хранилища, мини-фраз, размеров 360/390/768/1440, reduced motion и интерфейса кабинета. Для запуска нужен установленный пакет `playwright`; можно задать `PLAYWRIGHT_MODULE` (URL модуля) и `CHROME_PATH`.

Тестовая запись `QA test / qa-check@example.com` создана при проверке живой базы и может быть удалена владельцем через кабинет. Контент и админская логика дополнительно проверены отдельным ревьюером; два важных замечания исправлены и покрыты проверками.
